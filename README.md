# Planet Barbershop Orchid — Website Demo

## Deskripsi Proyek

Website demo untuk Planet Barbershop Orchid yang berlokasi di Taman Baloi, Batam. Proyek ini dikembangkan sebagai bagian dari portofolio web development dengan fokus pada desain antarmuka yang modern, minimalis, dan responsif.

Website dirancang untuk memberikan gambaran bagaimana bisnis barbershop dapat menyajikan informasi layanan, lokasi, serta akses komunikasi dengan pelanggan melalui platform digital.

## Fitur Utama

- **Responsive Design** — Tampilan menyesuaikan berbagai ukuran layar, termasuk desktop dan perangkat mobile.
- **Navigasi Interaktif** — Memudahkan pengguna mengakses setiap bagian website.
- **Informasi Layanan** — Menampilkan bagian layanan dengan tautan untuk mengajukan pertanyaan melalui WhatsApp.
- **Galeri Visual** — Menampilkan ilustrasi bertema barbershop sebagai elemen visual pendukung.
- **Integrasi WhatsApp** — Menyediakan tautan langsung untuk komunikasi dengan pihak barbershop.
- **Integrasi Google Maps** — Menampilkan lokasi dan menyediakan akses ke petunjuk arah.
- **Animasi dan Interaksi** — Menggunakan CSS dan JavaScript untuk meningkatkan pengalaman pengguna.
- **Aksesibilitas Dasar** — Mendukung navigasi keyboard dan preferensi pengurangan animasi.

## Teknologi

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Google Maps Embed
- WhatsApp Click-to-Chat

Proyek ini menggunakan HTML, CSS, dan JavaScript dalam satu file sehingga dapat dijalankan sebagai website statis tanpa proses build tambahan.

## Status Proyek

**Status: Prototype / Portfolio Demo**

Website ini masih berupa prototipe untuk keperluan demonstrasi. Informasi layanan, harga, jam operasional, dan aset visual perlu diverifikasi atau disesuaikan sebelum digunakan secara resmi.

## Tujuan Pengembangan

Proyek ini bertujuan untuk menerapkan prinsip desain antarmuka, pengembangan website responsif, dan integrasi layanan eksternal dalam sebuah solusi digital untuk bisnis lokal.

## Deployment

Website dapat di-hosting sebagai website statis menggunakan GitHub Pages.
